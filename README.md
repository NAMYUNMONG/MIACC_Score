# MIACC_Score

브라우저에서 동작하는 **콘티/악보 준비 웹앱**입니다.

## 구현 기능
1. 곡 제목/레퍼런스/조성 입력 후 곡 추가
2. 위키피디아 기반 조성(Key) 자동 추론(입력 비워둔 경우)
3. Google 이미지/IMSLP/MuseScore/YouTube 레퍼런스 후보 링크 자동 생성
4. 선택 악보 이미지 업로드 및 미리보기
5. 곡별 섹션 토글 + 흐름 순서 편집
6. 특별 요청사항 입력
7. 곡별 편집 내용을 A4 세로 PDF로 export

## 실행 방법
정적 사이트라서 파일만 열어도 동작하지만, 권장 방식은 로컬 서버입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 사용 순서
1. 곡 제목/레퍼런스/조성 입력 후 **곡 추가 및 후보 생성** 버튼 클릭
2. 생성된 후보에서 **검색 열기**로 실제 포털/사이트 확인 후 **후보 선택**
3. 결정된 악보 이미지를 업로드
4. 섹션 토글 및 흐름 편집
5. 특별 요청사항 작성
6. **A4 세로 PDF 내보내기** 클릭

## 참고
- 외부 검색 엔진의 원본 이미지를 자동 수집/저장하지는 않고, 후보 검색 링크를 제공합니다.
- 자동 추론 Key는 참고용이며 최종 확인은 사용자가 해야 합니다.
