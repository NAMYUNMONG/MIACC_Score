3. FX Send / Return Controls M32에서 실제로 무엇을 조절하는지 대응해서 익히는 영역입니다.

FX Return → Same FX Bus
실제 오디오는 루프를 만들지 않고 경고만 표시합니다.
경고: FX Return을 자기 자신의 FX Send Bus로 다시 보내면 reverb가 반복 재입력되어 feedback/무한 tail 위험이 있습니다. 일반적인 send/return 운용에서는 해당 send를 -∞로 유지하세요.
Dry 경로 이론값0.0 dB
FX Input 이론값-12.0 dB
Wet Return 이론값-17.0 dB
개별 보컬만 FX가 많다?그 채널의 Send를 낮춥니다.
전체 Reverb가 많다?FX Return 또는 FX DCA를 낮춥니다.
Bus Master?기본적으로 0 dB 근처를 기준으로 두면 구조 파악이 쉽습니다.

Training Scenarios 버튼을 누른 뒤 fader를 움직이며 차이를 관찰하세요.

연습: Vocal Reverb 기본값에서 Channel Fader를 -20 dB까지 내려보세요. Post-Fader라면 FX Send도 함께 줄어듭니다.

Quick Rule

Monitor = 보통 Pre-FaderFX = 보통 Post-FaderReturn → Same FX Bus = -∞
권장 사고방식: 소스별 FX 양은 Channel Send, 해당 FX 전체 양은 FX Return/DCA, FX Bus Master는 특별한 목적이 없으면 기준점으로 고정.

2. Gate Threshold 아래의 작은 신호를 줄이는 교육용 gate입니다.

Gate Enable
Bypass와 비교해보세요.
Gate: 입력 레벨이 Threshold보다 높으면 Open, 낮으면 Range만큼 감쇠합니다.

3. Compressor Web Audio DynamicsCompressor를 사용한 교육용 동작입니다.

Compressor Enable
빠른 Attack은 transient를 더 강하게 제어하고, 느린 Attack은 첫 어택을 더 통과시킵니다. Ratio와 Threshold를 먼저 정한 뒤 Attack/Release를 조정하세요.

4. 4-Band EQ M32의 4-band EQ 개념을 단순화해 각 밴드를 Peaking EQ로 구현했습니다.

EQ Enable
Tip: EQ는 숫자를 맞추는 작업보다 문제를 듣고 필요한 만큼만 조정하는 것이 중요합니다.

Signal Order

Input→Gate→Compressor→EQ→Output
교육용 단순화: 실제 M32에서는 설정과 tap/insert 구성에 따라 세부 신호 흐름이 달라질 수 있으므로, 이 Lab은 Gate·Comp·EQ의 핵심 역할과 상호작용을 익히는 용도입니다.
