02 · BEFORE RESET백업 후 Factory Initialize

M32 MANUAL공식 매뉴얼의 SETUP → config에서는 Console / Show Data / Libraries 초기화를 선택할 수 있으며, Console 초기화를 실행하면 “initialize ALL settings” 확인 메시지가 표시됩니다. 초기화 전에 현재 Scene을 반드시 USB/PC에 저장하세요.

  1. 현재 Scene/Show를 USB와 PC 두 곳에 백업하고 파일명을 날짜와 함께 기록합니다.
  2. Main PA 또는 amplifier로 가는 출력은 mute하거나 downstream 장비를 내려 초기화 중 돌발 출력을 막습니다.
  3. SETUP → config에서 초기화 대상을 Console로 선택하고 Factory state로 초기화합니다.
  4. 초기화 후 모든 channel mute, Main/Matrix output 상태, 48V 상태를 눈으로 다시 확인합니다.
  5. 이 상태를 00_RESET_BASE 같은 이름으로 즉시 저장합니다.

Sample Rate

예배·영상 환경에서는 48 kHz를 기본값으로 권장합니다. M32는 44.1/48 kHz 설정을 지원합니다.

INTERNAL

M32 단독 사용이면 Clock Source를 Internal로 둡니다. AES50 장치를 나중에 추가하면 clock master/slave 구조를 다시 검토합니다.

04 · INPUT ROUTINGUser In으로 물리 입력과 Channel Strip 분리

교회 고정 설치에서는 User In 1 = Pastor L, User In 2 = Pastor R … User In 30 = Mac R처럼 “논리 입력표”를 먼저 만들고, 각각이 실제 Local/AES50 몇 번인지 매핑하는 방식을 권장합니다. 이렇게 하면 천장/벽체 배선 번호가 바뀌어도 FOH의 CH1–30 순서는 유지됩니다.

  1. ROUTING에서 User Input page를 열고 위 표의 Physical Input 열을 기준으로 User In 1–30을 지정합니다.
  2. Input Routing block을 User 1–8 / User 9–16 / User 17–24 / User 25–32로 받도록 구성합니다.
  3. 각 Channel Strip의 Source가 자기 User Input을 바라보도록 정리합니다.
  4. 스테레오 pair는 실제 Left/Right가 뒤집히지 않았는지 반드시 meter와 PFL로 확인합니다.
  5. Routing만 완료한 상태를 02_ROUTING으로 저장합니다.
절대 주의User Routing을 만든 뒤 Channel 이름만 보고 믿지 마세요. 실제 마이크 하나씩 두드리거나 말해서 CH 번호가 맞는지 Line Check로 검증해야 합니다.

07 · GAIN STAGINGGain은 “Volume”이 아니라 입력의 기준점

각 source를 예배에서 실제로 낼 가장 큰 수준으로 받아서 Gain을 맞춥니다. 실전 시작점은 정상 peak가 대략 -18 ~ -12 dBFS 부근에서 움직이고, 큰 순간 peak도 대체로 -6 dBFS보다 충분히 아래에 있도록 여유를 두는 방식이 안전합니다. 숫자는 목표가 아니라 headroom 확보를 위한 가이드입니다.

  1. 채널 fader는 임시로 낮추고, PFL/Solo meter로 preamp level을 봅니다.
  2. 설교자는 실제 큰 발성, 싱어는 후렴 최대 성량, 악기는 공연 강도로 연주합니다.
  3. Wireless receiver, keyboard, FM9, E-Drum 모듈 등 소스 장비 output이 지나치게 낮지 않은지 먼저 확인합니다.
  4. Gain을 올려 디지털 입력 레벨을 확보하되 clip을 만들지 않습니다.
  5. 모니터/P16을 맞춘 이후에는 큰 Gain 변경을 피합니다. Gain 변경은 FOH 외에도 monitor source level에 영향을 줍니다.
Mic
GAIN AT PREAMP

마이크 거리와 실제 성량이 가장 큰 변수입니다. EQ로 보상하기 전에 거리/방향을 먼저 고칩니다.

Line / DI
SOURCE OUTPUT FIRST

소스 output이 지나치게 낮은 상태에서 M32 Gain만 과하게 올리지 않습니다. 반대로 너무 뜨거운 line signal은 source에서 낮춥니다.

14 · SOUND CHECK개별 소스 → Group → Full Band 순서

STEP 1
Speech 먼저: Pastor L/R. 두 마이크 위상·거리·feedback margin을 확인하고, 말이 명확해지는 최소 processing만 적용.
STEP 2
Singers: Leader → BGV1–6. Gain/HPF/Compression을 맞추고 동일한 BGV processing은 Library/Copy를 활용하되 각 목소리에 맞게 수정.
STEP 3
Rhythm/Band: Bass → E-Drum → Keys → Guitars. 저역을 먼저 정리하고 Key/Guitar의 midrange 충돌을 해결.
STEP 4
Acoustic: Psalm → Organ → Piano → Violin → Cello. 마이크 위치와 룸 bleed를 우선 확인.
STEP 5
Choir: 4개를 하나씩 확인한 뒤 같이 열어 spacing/phase/feedback을 확인. 필요 이상으로 4개 모두 크게 올리지 않음.
STEP 6
Playback: Windows/Mac의 영상·음원 최대 level을 확인. 갑작스러운 content level 차이를 대비.
STEP 7
P16: musician에게 개인 mix를 만들게 한 뒤 FOH gain 변경 없이 필요한 수정만 처리.
STEP 8
FX: Dry balance가 완성된 후 Plate/Hall/Delay를 추가. FX로 부족한 mix를 가리지 않음.

15 · FULL MIX찬양팀 전체 · 객석에서 최종 Balance

1. Vocal Priority
MESSAGE FIRST

Leader와 회중이 따라야 하는 핵심 가사가 명확해야 합니다. BGV는 풍성하게 하되 leader를 가리지 않습니다.

2. Low-End Foundation
BASS + E-DRUM

Bass와 kick 성분이 서로 겹치면 한쪽을 boost하기보다 역할을 분리합니다.

3. Midrange Space
KEY + GUITAR + VOCAL

2–5 kHz 영역에서 모든 악기가 앞으로 나오려 하면 피곤한 믹스가 됩니다.

FOH 가운데 한 자리만 듣지 말고 Front / Middle / Rear를 빠르게 이동하며 vocal-to-band 비율과 high-frequency coverage를 확인합니다. Delay/Rear speaker가 있다면 전환 지점에서 level과 시간 정렬이 자연스러운지도 확인합니다.

실전 판단 루프Listen → 문제를 한 문장으로 정의 → 가장 영향이 적은 조절 하나만 → 다시 전체를 듣기. EQ·Fader·FX를 동시에 움직이지 않습니다.

APPENDIX B장비별 현장 메모

Shure QLXD / BLX 무선
Receiver의 RF와 AF를 먼저 확인하고, console gain 이전에 receiver output level이 정상인지 확인합니다. 무선 수신기 출력에는 M32 phantom을 기본 OFF로 둡니다. 본 예배 전에 배터리와 RF 상태를 반드시 확인합니다.
Roland RD-2000 / Yamaha MODX7+
L/R를 실제 stereo로 사용하므로 Left/Right cable과 link/pan을 확인합니다. 소스 patch마다 master output 차이가 크지 않도록 keyboard 내부 patch level도 관리합니다. 저역이 Bass와 충돌하면 console EQ 이전에 patch voicing도 검토합니다.
FM9 Direct
가능하면 balanced line output을 사용하고 phantom은 OFF. FOH가 FM9 tone을 다시 만드는 것이 아니라 전체 mix 안에서 HPF/harshness 정도를 최소 보정하는 접근이 좋습니다.
DI — A.Guitar / Bass / E-Drum / Psalm
Active/Passive DI 종류를 라벨에 기록합니다. Phantom powering을 사용할지 배터리/어댑터를 사용할지 현장에서 통일하면 실수가 줄어듭니다. Hum이 있을 때 Ground Lift를 사용하되 보호 접지를 임의로 제거하지 않습니다.
Organ SM58 / Grand Piano SM57
이 두 소스는 console EQ보다 mic placement 변화가 더 큰 영향을 줄 수 있습니다. 먼저 스피커 cone/organ cabinet 위치, piano soundboard/hammer 쪽 위치를 조정한 뒤 EQ합니다.
Violin / Cello Condenser
48V 필요 여부를 확인하고 mic distance를 너무 가깝게 두지 않습니다. 무대 monitor/PA에 가까울수록 feedback과 bow harshness가 커질 수 있어 위치와 방향을 먼저 최적화합니다.
Choir Ceiling Condenser ×4
4개 모두를 동일하게 크게 여는 것보다 실제 choir 위치와 coverage에 맞춰 최소한으로 사용합니다. HPF로 room rumble과 stage low-end를 정리하고, hard gate는 피하며 feedback band를 좁게 cut합니다. DCA 7로 전체 choir level을 제어합니다.
Windows / Mac Playback
가능하면 balanced interface 또는 stereo DI/isolator를 권장합니다. 음원/영상마다 level 차이가 크므로 실제 가장 큰 content를 재생해 headroom을 확인하고, Mute Group 4로 playback을 빠르게 제어할 수 있게 합니다.
