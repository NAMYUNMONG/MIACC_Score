MIDAS M32
Appendix · 고급 참고편

메인 매뉴얼에서 일부러 덜어낸 Routing, P16, Network/M32-Edit, Show Control, Matrix, RTA, FX 등의 기능을 필요할 때 찾아볼 수 있도록 분리했습니다.

A · ROUTING — A1Routing — Source와 Destination을 분리해서 생각하기

OFFICIALM32의 ROUTING 화면은 콘솔 내부 신호 경로와 물리 입·출력 커넥터 사이의 패치를 설정하는 곳입니다. 공식 매뉴얼에는 home, out 1-16, aux out, p16 out, card out, aes50-a/b, xlr out 탭이 설명됩니다.

PHYSICAL SOURCELocal XLR / Aux
→
INPUT CHANNELCh 1–32
→
PROCESS / BUSDirect · Bus · Main
→
PHYSICAL DEST.XLR · P16

ROUTING → home

로컬 입력을 32개 Input Channel에 연결합니다. 기본 상태에서는 Local 1–32가 대응하는 채널 1–32에 연결되지만, 8채널 단위로 다른 소스 블록을 패치할 수 있습니다.

ROUTING → out 1-16

16개 아날로그 XLR Output에 Main, Mix Bus, Matrix, Direct Out, Monitor 등을 지정합니다. 여기에서 무엇을 출력할지와 어느 Tap Point에서 가져올지를 함께 결정합니다.

예배 중 주의Routing은 잘못 바꾸면 여러 채널이 한꺼번에 사라질 수 있습니다. 예배 중 문제가 단순 Fader/Mute 수준인지 확인하기 전에 Routing부터 바꾸지 마세요.

A · ROUTING — A2Tap Point — “어느 지점의 소리”를 보낼 것인가

M32의 Output/P16 Routing에서는 IN/LC, PreEQ, PostEQ, PreFdr, Post Fader 등의 Tap Point를 선택할 수 있습니다.

Tap뜻교회 사용 관점
IN/LC입력/Low Cut 부근의 이른 지점콘솔 가공을 최소화한 소스가 필요할 때
PreEQEQ 이전FOH EQ와 독립적인 모니터 소스가 필요할 때 검토
PostEQEQ 이후FOH에서 정리한 톤을 모니터에도 반영하고 싶을 때
PreFdr채널 Fader 이전FOH Fader 변화와 모니터 레벨을 분리할 때
Post Fader채널 Fader 이후FOH 레벨 변화가 목적지에도 따라가야 할 때
선택 원칙P16은 연주자 개인 믹스이므로 FOH Fader가 움직일 때 연주자 레벨까지 같이 움직이길 원하는지 먼저 결정하세요. 이것이 Tap Point 선택의 출발점입니다.

A · ROUTING — A3P16 Ultranet 상세 Routing

OFFICIALROUTING → p16 out은 16개 P16 채널 각각에 Source Category와 특정 Signal Path, Tap Point를 지정합니다. 공식 매뉴얼은 P16에 스테레오 키보드, 기타, 베이스, 보컬 등의 stem을 보내 연주자가 개인 믹스를 만드는 사용법도 명시합니다.

  1. ROUTING → p16 out을 엽니다.
  2. Encoder 1로 P16 1–16 중 설정할 채널을 선택합니다.
  3. Source Category에서 Main / Mix Bus / Matrix / Direct Out 등을 고릅니다.
  4. 구체적인 Source를 선택하고 Assign합니다.
  5. Tap Point를 선택하고 Assign합니다.
  6. P16 장치에서 실제 신호·채널명·레벨을 확인합니다.

추천 설계 방식

방식장점단점
개별 Direct Out연주자가 각 악기/보컬을 독립 조절16채널을 빠르게 소진
Stem / BusChoir, Singers 등 여러 채널을 묶어 효율적Stem 내부 밸런스는 연주자가 변경 불가
혼합형Keys/Drums는 Stereo, Vocals는 Stem 등 실용적초기 설계가 필요
현재 구성 추천Main Key와 Aux Key, E-Drum은 스테레오를 유지하고 A.Gtr/E.Gtr/Bass는 개별, 싱어·성가대는 채널 여유에 따라 개별 또는 Stem으로 배치하는 혼합형이 적합합니다.

B · CONTROL — B1M32-Edit · Network — 원격 편집을 안전하게 사용하기

제공된 M32 공식 매뉴얼은 네트워크 설정에서 IP Address, Subnet Mask, Gateway를 설정할 수 있다고 설명하며, Ethernet을 통해 외부 편집/원격 제어 소프트웨어를 사용할 수 있음을 안내합니다. M32-Edit의 버전별 화면 배치는 제공 PDF의 범위를 넘어가므로 여기서는 연결과 운영 원칙만 다룹니다.

  1. M32의 SETUP → network에서 IP / Subnet / Gateway를 확인합니다.
  2. M32와 M32-Edit PC를 같은 네트워크 대역에 연결합니다.
  3. 연결 후 먼저 현재 콘솔 상태가 PC에 정확히 반영되는지 확인합니다.
  4. Routing/48V/Scene처럼 영향이 큰 변경은 현장 콘솔 화면과 함께 재확인합니다.
  5. 예배 전에는 M32-Edit에서 대량 Paste/Recall/Library 작업을 피하고 Scene 백업 후 진행합니다.
Remote와 M32-Edit 구분공식 매뉴얼의 SETUP → remote는 DAW Control Surface(HUI/Mackie/MIDI) 기능 설명입니다. 일반적인 M32-Edit 네트워크 원격 제어와 혼동하지 마세요.

B · CONTROL — B2Scenes · Snippets · Cues

OFFICIALSHOW CONTROL 영역은 설정에 따라 저장된 Cue, Scene, Snippet을 선택·활성화·이동하는 데 사용합니다.

개념운영 관점
Scene예배/공연의 비교적 큰 콘솔 상태를 저장·호출
Snippet필요한 일부 파라미터만 선택적으로 바꾸는 용도
CueScene/Snippet 등을 순서에 따라 운영하는 개념
교회 추천초보 단계에서는 “주일예배 기준 Scene”을 안정적으로 관리하는 것부터 시작하고, Snippet/Cue는 예배 순서 자동 전환이 실제로 필요한 경우에만 확장하는 것이 좋습니다.

B · CONTROL — B3Mute Group · Assign

M32에는 6개의 Mute Group이 있으며 여러 채널을 빠르게 동시에 Mute/Unmute할 수 있습니다. Assign 영역은 사용자 지정 컨트롤을 구성할 때 사용합니다.

Mute Group 예시대상
1 · All Singers찬양팀 무선 마이크
2 · BandKeys / Guitars / Bass / E-Drum
3 · Choir성가대 마이크
4 · Speech설교자/진행 마이크 중 운영 방식에 맞는 것
5 · FX Returns리버브/딜레이 Return
6 · Spare특별순서/행사
주의Mute Group 하나에 설교자와 찬양팀을 무심코 함께 넣으면 예배 순서 전환에서 사고가 납니다. 이름을 역할 중심으로 명확히 지정하고 실제 버튼을 눌러 검증하세요.

B · CONTROL — B4Talkback

공식 매뉴얼에 따르면 M32의 외부 Talkback XLR 입력은 48V 팬텀을 제공할 수 있고, Talkback 신호는 Mix Bus 1–16, LR Bus, Centre/Mono 등 여러 목적지로 보낼 수 있습니다.

교회에서는 Talkback을 연주자 모니터/P16용 커뮤니케이션으로 사용할 때 Main LR에 실수로 나가지 않도록 목적지를 명확히 제한하는 것이 중요합니다.

C · OUTPUT / FX — C1Matrix — Main을 다시 목적별로 나누기

M32는 6개의 Matrix를 제공합니다. Matrix는 이미 만들어진 Main/Bus 계열 신호를 다시 받아 로비, 방송, 보조 스피커 같은 별도 목적지로 보내는 데 유용합니다.

현재 환경현재 “M32 본체 중심 예배 PA”에서 별도 Zone이 없다면 Matrix는 필수 기능이 아닙니다. 필요 시 Appendix에서만 참고하고 메인 매뉴얼의 기본 workflow에는 넣지 않았습니다.

C · OUTPUT / FX — C2RTA · GEQ — 보이는 그래프를 정답으로 착각하지 않기

공식 매뉴얼의 RTA는 선택 신호의 주파수 분포를 실시간 Bar Graph 또는 Spectrograph로 표시하고, Channel EQ/Graphic EQ 위에 Overlay할 수 있습니다.

  • RTA는 “문제가 있는 주파수 후보”를 찾는 도구입니다.
  • 실제로 듣지 않고 그래프만 평평하게 만드는 것이 목표가 아닙니다.
  • 피드백 대응 시 큰 노치를 여러 개 만드는 대신 원인 마이크와 스피커 위치를 먼저 확인합니다.

C · OUTPUT / FX — C3Internal FX — 8개 Processor

공식 매뉴얼은 8개의 내부 Effects Processor를 제공하며 Effect Type, Input/Output Path, Level, Parameter를 설정할 수 있다고 설명합니다. Reverb, Delay뿐 아니라 Dynamics/EQ 계열 등 다양한 모델이 있습니다.

예배용 우선순위추천 용도
Reverb찬양 보컬/성가대의 공간감
Delay특정 찬양의 리드 보컬 효과
GEQBus/Main 보정 및 모니터 피드백 관리
기타 FX필요성이 분명할 때만

C · OUTPUT / FX — C4USB Recorder — 제공 M32 매뉴얼 기준

제공된 M32 매뉴얼은 전면 USB Port에서 FAT 형식 USB 저장장치로 WAV 재생 및 스테레오 녹음을 할 수 있다고 설명합니다. 기본 녹음 Source는 Main L/R이며 Recorder의 VIEW 화면에서 Source를 선택할 수 있습니다.

M32 LIVE 모델 주의아래 D2에서 설명하듯 제공 PDF는 DN32-USB 카드 기반 설명을 포함합니다. M32 LIVE의 DN32-LIVE/SD 카드 관련 기능은 이 문서의 근거와 모델이 다를 수 있어 별도 공식 매뉴얼 없이 상세 절차를 추가하지 않았습니다.

D · REFERENCE — D1현재 환경에서 우선순위가 낮은 기능

AES50 A/B
디지털 스테이지박스 등 AES50 장비를 연결할 때 사용합니다. 현재 M32 로컬 입출력 단독 운용이라는 전제에서는 일상 작업에서 다루지 않습니다.
Card I/O / DAW Recording
제공 M32 매뉴얼은 DN32-USB를 통한 32×32 컴퓨터 오디오를 설명합니다. 현재 예배 운영에 멀티트랙 DAW가 없다면 필수 항목이 아닙니다.
DAW Remote (HUI / Mackie Control)
M32의 Group/Bus Fader를 DAW Control Surface로 쓰는 기능입니다. 일반 M32-Edit 원격 제어와 다른 기능입니다.
MIDI
Scene 변화나 외부 장비 제어 등 자동화가 필요한 경우 확장할 수 있으나 초보–중급 예배 workflow에서는 후순위입니다.

D · REFERENCE — D2M32 LIVE와 제공 PDF의 모델 범위

중요제공된 PDF 표지는 M32 User Manual이며 본문 Rear Panel/Card 설명은 KLARK TEKNIK DN32-USB를 기준으로 합니다. 따라서 이 Appendix는 M32 콘솔 공통 조작을 중심으로 작성했으며, M32 LIVE의 DN32-LIVE 카드/SD 멀티트랙 녹음 기능은 의도적으로 상세화하지 않았습니다.

M32 LIVE 고유 카드 기능까지 포함하려면 해당 카드 또는 M32 LIVE 버전에 맞는 공식 문서를 추가 기준으로 삼는 것이 안전합니다. 반면 Input Channel, Preamp, Gate, Dynamics, EQ, Bus, DCA, Routing, P16, Scene 등 콘솔 핵심 workflow는 제공 M32 매뉴얼을 기준으로 정리했습니다.
