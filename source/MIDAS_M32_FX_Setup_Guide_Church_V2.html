0 · QUICK START — 0.1FX 핵심 5분 요약

예배 믹싱에서 가장 많이 쓰는 FX는 사실상 Reverb와 Delay입니다. M32의 다양한 효과를 모두 알아야 좋은 믹스가 되는 것은 아닙니다. 먼저 아래 네 가지를 안정적으로 다루는 것이 우선입니다.

① Vocal Reverb
DEPTH WITHOUT LOSING CLARITY

리드·백업 보컬을 한 공간 안에 묶되 가사가 뒤로 물러나지 않게 합니다. Pre-delay, Decay, Lo/Hi Cut이 핵심입니다.

② Vocal Delay
TEMPO / THROW / WIDTH

모든 구간에 많이 거는 대신, 필요할 때만 적당히 보내거나 특정 구절에 Delay Throw처럼 사용하는 것이 효과적입니다.

③ Choir / Space Reverb
CHOIR & AMBIENCE

성가대 콘덴서에는 리드보컬과 다른 공간감을 주는 편이 관리하기 쉽습니다. 이미 실제 홀 잔향이 많다면 아주 적게 사용합니다.

④ Drum / Instrument Space
SHORT ROOM / PLATE

E-Drum이나 지나치게 건조한 소스에 짧은 Room/Plate를 더해 인공적인 건조함을 줄입니다. Bass·설교에는 대개 최소화합니다.

가장 중요한 원칙FX는 “들리게 만드는 것”보다 “없애면 허전한 정도”가 좋은 출발점입니다. 특히 교회는 가사 전달과 말씀 명료도가 우선이므로, 리버브가 예쁘게 들리는 것보다 직접음이 분명한지 먼저 확인합니다.
Send/Return에서 MIXPRACTICEFX를 별도 Bus로 보내고 FX Return으로 다시 받는 일반적인 parallel send/return 구성에서는 FX processor의 Mix를 보통 100% Wet에 두고, 실제 효과 양은 각 채널의 Send와 FX Return fader로 정하는 방식이 가장 관리하기 쉽습니다. Insert로 쓸 때는 Dry/Wet Mix를 효과 목적에 맞게 조정합니다.

1 · BASIC SETUP — 1.1M32 콘솔에서 Reverb / Delay 하나를 만드는 전체 순서

아래는 “리드 보컬용 FX1 Reverb”를 만드는 예시입니다. 실제 Mix Bus 번호는 현재 Scene에서 확인하세요.

  1. FX slot 확인 — Main Display 옆 EFFECTS 버튼을 누르고 home으로 갑니다. FX1에 어떤 processor가 들어있는지, input source가 무엇인지 확인합니다.
  2. Effect type 선택 — FX1을 선택한 뒤 5번 encoder로 Plate Reverb / Vintage Reverb / Hall Reverb 등 원하는 종류를 찾고 눌러 assign합니다.
  3. Input source 지정 — FX1의 left/right input에 사용할 Mix Bus를 지정합니다. Mono bus를 stereo reverb로 사용할 때는 공식 매뉴얼의 안내대로 좌·우 input source를 동일한 signal path로 설정할 수 있습니다.
  4. FX parameter 편집 — 6번 encoder 또는 FX1 탭으로 들어가 Pre Delay, Decay, Lo Cut, Hi Cut 등을 조정합니다. 필요하면 UP/DOWN으로 다음 parameter layer를 봅니다.
  5. FX Return 확인 — input fader section의 AUX IN / USB layer에는 FX Returns가 포함됩니다. FX1 Return L/R가 Mute되지 않았는지, Main Stereo Bus로 보내지고 있는지 확인하고 return fader를 올립니다.
  6. 보컬을 FX Bus로 Send — 리드보컬 채널에서 해당 FX Send Mix Bus로 보내는 양을 천천히 올립니다. SENDS ON FADER를 사용하면 선택한 Bus에 각 input이 얼마나 보내지는지 fader로 조정할 수 있습니다.
  7. 전체 믹스에서 판단 — Solo로 FX만 오래 듣지 말고, 밴드와 싱어가 함께 연주하는 상태에서 가사가 여전히 분명한지 확인합니다.
Sends on Fader 주의FX Send를 조절한 후에는 SENDS ON FADER가 켜져 있는지 반드시 확인하고 원래 상태로 복귀하세요. 켜진 상태에서 input fader라고 생각하고 움직이면 실제로는 선택한 Bus의 send level을 바꾸게 됩니다.
한 채널에서 Send를 조절하는 두 가지 사고방식
방법 A: Bus를 선택 → Sends on Fader
FX Send Bus를 SEL → SENDS ON FADER → input layer에서 각 fader로 send를 조절합니다. 여러 보컬의 FX 양을 한 번에 비교하기 좋습니다.

방법 B: Input을 선택 → Bus Sends
보컬 channel SEL → Bus Sends section에서 해당 FX Bus의 send를 조절합니다. 한 채널만 빠르게 조정할 때 편합니다.

1 · BASIC SETUP — 1.2M32-Edit에서 FX를 다룰 때의 흐름

PRACTICEM32-Edit은 콘솔의 routing/FX 상태를 큰 화면에서 한눈에 확인하는 데 특히 유용합니다. 버전에 따라 버튼 위치나 그래픽은 조금 달라질 수 있지만, 사고방식은 콘솔과 같습니다.

FX Rack
WHAT IS LOADED?

FX1–8에 어떤 model이 들어있는지와 FX1–4의 input source를 먼저 확인합니다.

Sends
WHO GOES INTO FX?

Input channel의 Sends에서 Reverb/Delay bus level을 비교합니다. 여러 singer의 send 차이를 한눈에 보기 좋습니다.

FX Returns
HOW MUCH WET RETURNS?

FX Return 1–4의 mute, pan, fader, Main LR assign을 확인합니다. FX가 안 들릴 때 가장 먼저 볼 부분 중 하나입니다.

현장 팁예배 중에는 콘솔 fader/DCA로 큰 레벨을 빠르게 다루고, 리허설 때는 M32-Edit으로 FX parameter, bus send, return 상태를 세밀하게 확인하는 식으로 역할을 나누면 효율적입니다.

1 · BASIC SETUP — 1.3FX Gain Staging · Send와 Return을 왜 둘 다 봐야 하나

FX는 input channel 하나가 아니라 Channel → Send Bus → FX Processor → FX Return → Main 여러 단계를 거칩니다. 어느 한 단계가 너무 작거나 너무 크면 FX가 약하거나 거칠게 들립니다.

1 · BASIC SETUP — 1.4FX Return을 하나의 “악기 채널”처럼 관리하기

FX Return은 단순한 뒷단이 아니라 믹스 안에 들어오는 별도의 wet signal입니다. 따라서 fader, mute, routing 상태가 중요합니다.

  • 찬양이 끝나고 말씀으로 넘어갈 때 Vocal Reverb/Delay Return을 줄이거나 mute하면 전환이 깔끔합니다.
  • 리드 보컬 channel fader를 내려도 FX send가 pre-fader라면 tail이 예상보다 남을 수 있으므로 FX Send Bus의 pre/post 설정을 확인합니다.
  • 리허설에서 Return fader의 “기준점”을 정해두고, 예배 중에는 ±수 dB 내에서만 움직이는 방식이 안정적입니다.
  • FX Return에 지나치게 많은 저역이 있으면 전체 mix가 뿌옇게 느껴지므로 processor 내부의 LO CUT부터 활용하는 것이 효율적입니다.
찬양→설교 전환PRACTICEDelay Return은 즉시 줄이고, Vocal Reverb도 거의 0에 가깝게 정리하면 설교자의 consonant와 문장 끝이 또렷해집니다. 설교자에게는 필요하면 아주 짧은 Ambience 정도만 검토합니다.

1 · BASIC SETUP — 1.5AUX IN / USB · Bus Master · Sends on Fader — 실제 페이더는 어떻게 있어야 하나

OFFICIALM32 공식 매뉴얼에서 AUX IN / USB 버튼은 Aux 입력·USB Recorder와 FX 1–4 Returns가 있는 input layer를 불러옵니다. 또한 SENDS ON FADER가 활성화되면 input section의 fader는 “Main LR의 채널 볼륨”이 아니라 현재 선택한 Mix Bus로 보내는 Send level을 나타냅니다. 따라서 FX 운용에서는 현재 어떤 Layer / Mode를 보고 있는지를 먼저 확인해야 합니다.

가장 먼저 정리할 오해AUX IN / USB 화면의 FX Return fader와 FX Send Bus의 fader는 다른 역할입니다. Return은 FX에서 처리되어 돌아온 wet signal의 최종 양, Send Bus는 FX processor로 들어가는 입력 총량입니다. 두 페이더를 서로 보상하듯 극단적으로 반대로 두지 않는 것이 안정적입니다.

② 가장 안정적인 “기준 상태”부터 만들기

PRACTICE아래는 Send/Return 방식의 Vocal Reverb 하나를 세팅할 때 쓰기 쉬운 기준점입니다. M32 제조사의 필수값이 아니라 gain structure를 단순하게 유지하기 위한 실전 workflow입니다.

위 dB 범위는 “잘 들리는 정답값”이 아니라 처음 소리를 만들기 위한 안전한 출발점입니다. 실제 결과는 preamp gain, source level, effect model의 내부 output, 홀 잔향에 따라 크게 달라집니다.

왜 Bus Master와 Return을 0 dB에서 시작하나고정된 두 단계는 Unity 근처에 두고 각 source Send에서 wet amount를 만든다는 규칙을 쓰면, 나중에 “어느 단계 때문에 리버브가 작은지” 찾기 쉽습니다. 리허설 이후에는 필요에 따라 Return을 몇 dB 낮춰 저장해도 되지만, Bus Master −20 dB / Return +10 dB처럼 서로 보상하는 구조는 피하는 편이 좋습니다.

③ AUX IN / USB 버튼을 눌렀을 때 무엇이 보여야 하나

이 layer에는 FX Return만 있는 것이 아니라 Aux 입력과 USB 관련 return도 함께 존재합니다. 따라서 “AUX layer의 모든 fader를 올리는 것”은 잘못된 접근입니다. 실제로 쓰는 source만 관리합니다.

FX2 Return L/RFX2를 사용한다면 위와 동일. 사용하지 않으면 내려두거나 MuteDelay 등 사용하지 않는 FX return이 열려 있을 필요는 없습니다.
FX3/4 Return L/R사용하는 FX만 활성화Choir/Drum FX 등을 실제 운용할 때만 Main에 포함합니다.
FX Return fader가 0 dB여야만 하는가?아닙니다. 절대적인 정답 위치는 없습니다. 다만 처음 세팅할 때 0 dB를 기준으로 잡으면 Send와 processor I/O를 판단하기 쉽습니다. 이후 전체 리버브가 많다면 Return을 −3~−6 dB 정도 줄이는 식으로 fine-tune할 수 있습니다. 반대로 Return을 매우 낮게 두고 Send를 과도하게 올려 processor input을 뜨겁게 만드는 것은 피합니다.

④ SENDS ON FADER 상태에서 AUX IN / USB layer를 보면 특히 주의

FX Send Bus를 선택하고 SENDS ON FADER가 켜져 있으면, 그 상태에서 AUX IN / USB layer로 넘어갔을 때도 fader는 “Return의 Main level”이 아니라 Aux/USB/FX Return 채널이 현재 선택한 Bus로 보내는 Send 양을 나타냅니다.

⚠ FX Return → 자기 자신의 FX Send Bus는 반드시 −∞
예: FX1 Reverb가 어떤 Mix Bus를 input으로 사용하고 있다면, FX1 Return을 다시 그 같은 Mix Bus로 보내지 마세요. Wet signal이 다시 Reverb로 들어가 반복 순환하면서 tail이 계속 커지거나 feedback처럼 폭주할 수 있습니다. 특별한 serial FX 설계를 의도한 경우가 아니라면 FX Return들의 FX Send는 기본적으로 −∞가 안전합니다.

⑤ 실제 예배에서 무엇을 어느 fader로 움직일까

“리드보컬만 리버브가 너무 많다”
Lead Vocal → 해당 FX Bus Send를 낮춥니다. Return 전체를 내리면 다른 보컬도 함께 줄어듭니다.
“모든 보컬의 리버브가 전체적으로 많다”

“FX processor input meter가 너무 뜨겁다”
개별 Send가 전반적으로 과한지 확인하고, 필요하면 FX Send Bus Master를 낮춰 processor input gain을 정리합니다.
“리버브가 안 들리는데 Dry vocal은 정상”

“찬양에서 설교로 바로 넘어간다”
Delay Return은 우선 빠르게 줄이거나 Mute. Vocal Reverb Return도 크게 줄이고, Pastor Send가 −∞인지 확인합니다.
“한 곡만 Reverb를 더 풍성하게 하고 싶다”
Bus Master보다 FX Return을 약간 올리거나 해당 보컬 Send를 올리는 방식이 예측하기 쉽습니다. 곡이 끝나면 기준값으로 복귀합니다.

⑥ FX1 Reverb 예시 — 실제 버튼 순서

  1. EFFECTS → home에서 FX1 input source가 어느 Mix Bus인지 확인합니다. 예를 들어 현재 Scene에서 FX1이 Bus 13을 사용한다면 이후 절차에서 Bus 13을 선택합니다.
  2. BUS MAST layer에서 해당 Bus Master를 Mute OFF, fader는 우선 0 dB 근처에 둡니다.
  3. 해당 Bus의 SEL → SENDS ON FADER ON → INPUTS 1–16 / 17–32에서 리버브가 필요한 채널만 올립니다.
  4. 같은 Sends on Fader 상태에서 AUX IN / USB layer를 확인하고, FX Return이 그 FX Bus로 다시 보내지고 있지 않은지(−∞) 확인합니다.
  5. SENDS ON FADER OFF. 이제 AUX IN / USB는 다시 정상 채널 level을 표시합니다.
  6. FX1 Return L/R의 Mute OFF / Main LR assign / fader 기준값을 확인합니다. 처음에는 0 dB 부근에서 시작하는 것이 구조를 이해하기 쉽습니다.
  7. Full band로 들으면서 Lead vocal Send를 먼저 조정하고, 그다음 BGV/Choir를 추가합니다. FX Return은 전체 효과가 너무 많거나 적을 때만 몇 dB 범위에서 움직입니다.

2 · REVERB — 2.1Reverb 파라미터를 “무엇이 바뀌는지” 기준으로 이해하기

Parameter들리는 변화교회 FOH에서의 사고방식
PRE DELAY직접음 뒤에 reverb가 시작되기까지의 시간늘리면 보컬 자음/가사와 tail이 분리되어 clarity 확보에 유리. 너무 길면 명백한 slap처럼 분리.
DECAY / REV TIMEreverb tail이 사라지는 시간길수록 웅장하지만 빠른 곡·말이 많은 구간에서 단어가 겹침. 홀 자체 잔향이 길면 짧게.
SIZE / ROOM SIZE가상 공간의 크기 인상실제 decay와 함께 공간의 scale을 정함. 항상 큰 SIZE가 좋은 것은 아님.
DAMP / DAMPINGtail 고역이 얼마나 빨리 어두워지는지고역 tail을 빠르게 줄이면 reverb가 뒤로 물러나고 sibilance가 덜 거슬림.
DIFFUSION / DENSITY초기 reflection의 밀도/부드러움높으면 촘촘하고 매끈, 낮으면 개별 reflection이 더 느껴질 수 있음.
SHAPEreverb envelope의 contour초기/후기 에너지 인상을 조정. 기본값에서 시작해 필요한 경우만 만짐.
LO CUTreverb로 들어가는 저역 제거가장 중요한 정리 도구. 저역 울림을 줄여 bass/kick과 speech clarity를 보호.
HI CUTreverb의 고역을 제한tail을 어둡게 하여 vocal 앞쪽의 자음/air와 경쟁하지 않게 함.
BASS MULT + XOVER저역 decay를 별도로 길게/짧게교회에서는 대체로 과한 low-frequency decay를 피하는 방향이 안전.
MOD DEPTH / SPEEDtail에 미세한 pitch/motion 추가너무 크면 chorus 느낌. 보컬은 낮게 시작.
LEVEL / TAIL GAINeffect output 또는 tail의 양Send/Return 시스템에서는 Return과 중복으로 “양”을 결정하므로 gain 구조를 일관되게 관리.
ER DELAY / ER LEVELEarly Reflection의 시간·크기공간의 가까움/거리감을 만들기 좋지만 과하면 직접음과 충돌.
SPINtail의 random modulation정적인 tail을 부드럽게 하지만 과사용 금지.
FREEZE현재 reverb를 사실상 지속시킴특수 연출용. 예배 일반 운용에서는 accidental activation 주의.
보컬 리버브를 선명하게 만드는 순서① LO CUT → ② HI CUT → ③ DECAY → ④ PRE DELAY → ⑤ Send 양 순서로 정리하면 초보자도 문제를 찾기 쉽습니다. “리버브가 많다”는 문제를 Return fader만 내리기보다, 먼저 tail의 저역과 길이가 불필요하게 많은지 확인하세요.

3 · DELAY — 3.1Delay 파라미터 완전정리

OFFICIALM32의 Stereo Delay는 master time을 최대 3초까지 조정하고 좌/우 rhythmic factor, offset, feedback, feedback filters와 ST/X/M feedback mode를 제공합니다. Triple/Rhythm Delay는 여러 tap의 factor·gain·pan을 개별 조절할 수 있습니다.

Parameter기능실전 판단

Triple Delay / Rhythm Delay

Triple Delay는 3개의 tap, Rhythm Delay는 4개의 tap을 두어 각 stage의 FACTOR, GAIN, PAN을 조절합니다. 반복이 분명한 CCM/modern worship texture에는 강력하지만, 리드보컬이 dense한 곡에서는 단순 Stereo Delay가 오히려 관리하기 쉽습니다.

3 · DELAY — 3.3찬양 보컬 Delay를 실전에서 쓰는 세 가지 방식

1. 항상 아주 낮게
SUBTLE BED

곡 전체에서 거의 인지되지 않을 정도로 유지. Reverb만으로 부족한 depth를 보완합니다. Feedback은 낮게, Hi Cut으로 반복음을 어둡게.

2. 후렴에서만 증가
SECTION LIFT

Verse는 낮게, Chorus에서 send/return을 몇 dB 올려 공간이 커지는 느낌을 만듭니다. DCA처럼 과격하게 올리기보다 작은 변화가 자연스럽습니다.

3. Delay Throw
LAST WORD THROW

문장 끝·특정 단어에만 send를 순간적으로 올려 반복시키고 바로 내립니다. 가장 효과적이지만 타이밍 실수가 눈에 띄므로 충분한 리허설이 필요합니다.

Throw 실수 방지Delay Send를 올리고 내리지 않으면 다음 문장이 계속 반복됩니다. “올림 → 단어 통과 → 즉시 원복”을 한 동작으로 연습하고, 필요하면 Assign 버튼/스니펫 같은 운영 자동화를 별도 검토하세요.

4 · OTHER FX — 4.2한 Slot에 두 효과를 넣는 Combination FX

OFFICIALM32에는 Delay + Chamber, Chorus + Chamber, Flanger + Chamber, Delay + Chorus, Delay + Flanger, Modulation Delay 같은 조합형 processor가 있습니다. slot 하나에서 두 효과의 balance를 조절할 수 있어 slot 절약에 유용합니다.

Delay + Chamber
PRACTICAL FOR VOCALS

BALANCE로 delay/reverb 비율, Time/Pattern/Feedback와 reverb Predelay/Decay/Size/Damping을 함께 다룹니다. FX slot을 아끼면서 보컬 space를 만들기 좋습니다.

Chorus + Chamber
THICK + SPACE

백업보컬이나 특정 keys를 넓히면서 reverb를 함께 줄 수 있습니다. 리드보컬에는 과하면 center focus가 흐려질 수 있습니다.

Delay + Chorus / Flanger
TEXTURE FX

Delay의 Time/Pattern/Feedback와 modulation의 Speed/Delay/Depth를 같이 조절합니다. 현대 worship texture에 쓸 수 있지만 기본 FX보다 복잡합니다.

Modulation Delay
PARALLEL / SERIAL

Delay와 modulation/reverb를 Parallel 또는 Serial로 구성할 수 있습니다. 음색 디자인용으로 강력하나 예배 중 즉석 수정에는 복잡하므로 preset화가 좋습니다.

5 · CHURCH WORKFLOW — 5.3FX Soundcheck는 이 순서로 진행

  1. 모든 FX Return을 내려두고 Dry Mix를 먼저 완성합니다. Gain, HPF/EQ, compressor, basic level/pan이 먼저입니다.
  2. Lead Vocal Reverb만 올립니다. Full band에서 vocal clarity가 유지되는 가장 작은 양을 찾습니다.
  3. Backing Vocal을 같은 Reverb로 보내 서로 하나의 group처럼 들리는지 확인합니다.
  4. Delay를 추가합니다. BPM time을 맞추고 feedback/return은 최소부터 올립니다.
  5. Choir Reverb를 별도로 맞춥니다. actual room sound를 포함한 전체 잔향을 듣습니다.
  6. Instrument/Drum space는 마지막에 추가합니다. 없어도 자연스럽다면 굳이 넣지 않습니다.
  7. 찬양 전체 rehearsal에서 fast song / slow song 모두 확인합니다. slow song에 맞춘 긴 decay가 fast song에서 muddy해지지 않는지 봅니다.
  8. 설교 전환을 실제로 연습합니다. Delay/Reverb return을 어느 시점에 줄일지 정합니다.

5 · CHURCH WORKFLOW — 5.4FX Preset · Scene · Library를 안전하게 관리하기

OFFICIALM32 LIBRARY → effects에서는 각 FX slot의 preset을 load/save하고 import/export할 수 있습니다. EFFECTS 화면에서 UTILITY를 누르면 effects Library로 바로 이동할 수 있습니다.

  • Processor preset: Plate Reverb의 parameter 자체를 저장. “Vocal Plate 2.1s” 같은 이름.
  • Scene: FX type뿐 아니라 sends, returns, routing 등 전체 console 상태와 연동될 수 있으므로 recall 범위를 주의.
  • 주일 운영: 잘 잡힌 기본 Scene은 보호하고, 새 FX 실험은 복제 Scene에서 진행한 뒤 비교합니다.
  • 목표: 매주 zero부터 만드는 대신, 80–90% 완성된 기준값을 불러오고 당일 singer/room에 맞춰 10–20%만 수정.
Recall 전에 확인FX preset 하나를 불러오는 것과 Scene 전체를 recall하는 것은 영향 범위가 다릅니다. 라이브 중에는 “무엇이 함께 바뀌는지” 확실히 알지 못하면 전체 Scene recall을 피하는 것이 안전합니다.
