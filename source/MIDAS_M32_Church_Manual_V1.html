PRACTICE현장 권장

1부 · 시작하기 — 1.4레이어 · SEL · VIEW — M32를 빠르게 다루는 법

초보자가 가장 많이 헷갈리는 부분은 “페이더가 움직였는데 왜 다른 채널인가?”입니다. M32는 같은 물리 페이더가 선택된 레이어에 따라 다른 채널을 제어합니다.

  1. 먼저 왼쪽 입력 페이더 영역에서 INPUTS 1-16 또는 INPUTS 17-32 레이어를 선택합니다.
  2. 수정할 채널의 SEL을 누릅니다.
  3. 상단 Channel Strip에서 Gain, Gate, Dynamics, EQ 등을 조절합니다.
  4. 더 자세한 값이 필요하면 해당 섹션의 VIEW를 누릅니다.
  5. 작업이 끝나면 현재 선택 채널과 레이어를 다시 확인한 뒤 다음 조작을 합니다.
특히 주의SENDS ON FADER가 켜져 있으면 입력 페이더는 Main 볼륨이 아니라 선택된 Bus로 보내는 Send Level이 됩니다. 모니터 작업 후 반드시 상태를 확인하세요.

1부 · 시작하기 — 1.5게인 · 48V · Low Cut

OFFICIALM32의 CONFIG/PREAMP 영역에서 선택 채널의 GAIN을 조절하고, 48 V 버튼으로 해당 물리 입력에 팬텀 전원을 공급합니다. LOW CUT은 32개 주요 입력 채널에서 사용할 수 있습니다.

48V Phantom Power

입력기본 판단이유
성가대 콘덴서48V 필요 가능성이 높음콘덴서 마이크의 액티브 회로 전원으로 흔히 사용
설교자 콘덴서마이크 방식 확인 후유선 콘덴서는 필요할 수 있으나, 무선 수신기 출력은 별도 확인 필요
싱어 무선 수신기보통 OFF수신기가 이미 출력 신호를 제공하므로 수신기 제조사 사양 우선
Keyboard / E-Drum / DI장비 사양 확인액티브 DI 중 팬텀으로 동작하는 제품도 있으므로 연결 방식에 따라 다름
운영 안전PRACTICE48V를 켜고 끌 때는 해당 채널을 Mute하고 메인 시스템에서 큰 팝 노이즈가 나오지 않도록 주의하세요. 팬텀 전원이 필요한지 확실하지 않은 장비에는 먼저 공급하지 않습니다.

Gain 잡기

제조사 매뉴얼은 Gain을 조절하는 기능을 설명하지만 모든 소스에 적용되는 하나의 “정답 미터 값”을 지정하지는 않습니다. 아래는 PRACTICE 디지털 라이브 콘솔의 실전 시작점입니다.

-40-24-18-12-60 dBFS
  • 연주자에게 예배 때 실제로 낼 가장 큰 소리를 내달라고 합니다.
  • 평균 신호가 충분히 보이고, 큰 피크가 0 dBFS에서 넉넉히 떨어져 있도록 Gain을 잡습니다.
  • 페이더로 부족한 Gain을 보상하지 말고, 반대로 Gain으로 전체 믹스 밸런스를 맞추지 않습니다.

2부 · 입력 소스별 가이드 — 2.1성가대 · Condenser Microphone

핵심 목표
CHOIR = 자연스러움 + 피드백 여유

성가대 마이크는 한 사람을 크게 받기보다 여러 사람과 공간을 함께 받습니다. 필요한 만큼만 올리고, PA 스피커와의 위치 관계를 가장 먼저 봅니다.

먼저 확인
BEFORE EQ
  • 직접 연결 콘덴서라면 48V 필요 여부
  • 마이크 방향과 성가대 거리
  • 메인 스피커보다 뒤/가까이에 있는지
  • 불필요한 무대 모니터가 마이크로 들어오는지
항목시작점조정 기준
Low Cut / HPF대략 100–150 Hz부터 검토발 울림·무대 진동·저역 뭉침을 줄이되 남성 저음이 지나치게 얇아지지 않게
Gate대체로 OFF 또는 매우 약하게여러 사람의 자연스러운 잔향이 끊기지 않게
Compression필요할 때만 가볍게큰 부분만 약간 안정화. 강한 압축은 피드백 여유를 악화시킬 수 있음
EQBoost보다 Cut 우선웅웅거림/먹먹함/쏘는 대역을 실제 공간에서 찾아 최소한으로 감쇄
교회 현장 팁성가대는 “EQ로 멋진 소리를 만드는 것”보다 마이크 배치와 충분한 Gain-before-feedback을 확보하는 것이 우선입니다. 피드백이 시작되면 해당 마이크 EQ만 보지 말고 스피커·마이크 위치와 전체 레벨도 함께 확인하세요.

2부 · 입력 소스별 가이드 — 2.2설교자 · Condenser Microphone

설교 음성은 예배에서 가장 높은 우선순위를 둡니다. 목표는 크게가 아니라 문장이 또렷하고 장시간 들어도 피곤하지 않게입니다.

  1. 마이크 방식에 따라 48V 필요 여부를 확인합니다.
  2. 설교자가 실제 발성으로 말할 때 Gain을 잡습니다.
  3. LOW CUT으로 책상 진동, 핸들링, 불필요한 저역을 정리합니다.
  4. EQ는 먼저 먹먹한 대역을 약하게 줄이고, 명료도가 부족할 때만 필요한 대역을 조금 보완합니다.
  5. 컴프레서는 큰 문장만 부드럽게 눌릴 정도로 사용합니다.
예배 중 조작설교 중 갑자기 작게 들릴 때 Gain을 크게 올리기보다 마이크 위치 → 발성 거리 → 채널 Meter → Main Fader → DCA를 순서대로 확인하세요. Gain을 크게 올리면 피드백 여유가 즉시 줄어듭니다.

2부 · 입력 소스별 가이드 — 2.3싱어 · Wireless Microphone

무선 싱어 마이크는 수신기 출력 레벨과 콘솔 Gain이 함께 작동합니다. 수신기에서 너무 작게 보내고 M32에서 과도하게 Gain을 올리는 구조를 피합니다.

항목권장 접근
48V무선 수신기 출력에는 일반적으로 사용하지 않으며, 해당 수신기 매뉴얼을 우선 확인
Low Cut대략 90–120 Hz 범위에서 시작하여 보컬 체형·마이크에 맞춰 조정
Gate거의 필요 없거나 매우 약하게. 가사 첫 음절이 잘리지 않도록 주의
Compressor2:1~3:1 정도의 가벼운 시작점. Gain Reduction을 들으며 결정
FX리버브는 보컬을 뒤로 보내므로 명료도와 예배 분위기 사이 균형
싱어 밸런스여러 싱어를 하나의 DCA로 묶어 전체 찬양 보컬을 빠르게 올리고 내리되, 개별 채널의 상대 밸런스와 EQ는 각 채널에서 유지하는 방식이 편리합니다.

3부 · 믹싱 핵심 — 3.1HPF · EQ · Gate · Compressor

M32 상단 Channel Strip은 선택된 채널의 핵심 처리를 바로 조작할 수 있게 구성되어 있습니다. 세부값은 각 섹션의 VIEW를 눌러 Main Display에서 확인합니다.

LOW CUT / HPF — 필요 없는 저역부터 정리

말·보컬·기타에서 무대 진동과 불필요한 저역을 줄이는 데 가장 먼저 확인합니다. “소리를 얇게 만드는 버튼”이 아니라 그 소스가 실제로 필요로 하지 않는 저역을 줄이는 필터로 생각하세요.

EQ — Boost보다 Cut을 먼저

M32 EQ는 여러 밴드의 주파수, Gain, 폭(Q)을 조절할 수 있습니다. 문제 대역을 찾을 때 큰 Boost를 유지한 채 탐색하지 말고, 잠깐 확인한 후 실제 처리는 작은 Cut부터 시작합니다.

Gate — 드럼 이외에는 보수적으로

Threshold 아래 신호를 감쇄합니다. 성가대·설교·싱어처럼 말이나 노래의 첫 음절이 중요한 소스에서는 과한 Gate가 더 큰 문제를 만듭니다.

Compressor — 큰 소리를 정리하는 자동 페이더

Threshold 위 신호를 Ratio에 따라 줄입니다. 보컬·베이스에 특히 유용하지만, 초보 단계에서는 Gain Reduction Meter가 계속 깊게 내려가는 설정보다 큰 부분에서만 반응하도록 시작하세요.

순서보다 중요한 것채널 처리의 세부 신호 순서는 설정에 따라 복잡해질 수 있습니다. 초보 단계에서는 “Gain을 먼저 안정화 → Low Cut → 문제 EQ → 필요할 때 Dynamics”의 작업 순서를 기억하는 것이 더 중요합니다.

3부 · 믹싱 핵심 — 3.2Main · DCA · Mute — 무엇을 어디서 조절할까

OFFICIAL선택 채널은 ST 버튼으로 Main Stereo Bus에 할당할 수 있습니다. DCA는 여러 채널의 오디오를 하나의 서브믹스로 합치는 것이 아니라, 원래 라우팅을 유지한 채 여러 채널의 레벨을 공통으로 제어합니다.

도구실제 기능교회 추천 사용
Channel Fader개별 채널 레벨싱어 1명, 기타 1대 등 세부 밸런스

4부 · 모니터 — 4.1Mix Bus · Sends on Fader

OFFICIALSENDS ON FADER는 선택된 Mix Bus로 각 채널이 얼마만큼 보내지는지 입력 페이더에서 직접 조절하게 해줍니다. M32 공식 매뉴얼도 특정 연주자의 모니터 믹스를 만드는 대표적인 사용법으로 설명합니다.

  1. 오른쪽에서 해당 연주자 모니터에 사용하는 Bus를 선택합니다.
  2. SENDS ON FADER를 눌러 활성화합니다.
  3. 왼쪽 입력 레이어 INPUTS 1-16 / 17-32를 선택합니다.
  4. 이제 왼쪽 페이더가 Main 레벨이 아니라 선택 Bus로 보내는 양을 표시합니다.
  5. 연주자의 요청에 따라 각 소스를 조절합니다.
  6. 작업 후 SENDS ON FADER 상태를 반드시 해제/확인합니다.
가장 흔한 사고Sends on Fader가 켜진 상태에서 “메인 보컬을 줄였다”고 생각했는데 실제로는 특정 연주자의 모니터에서만 줄어드는 경우가 많습니다. 화면과 버튼 점등을 습관적으로 확인하세요.

4부 · 모니터 — 4.2P16 Ultranet — 연주자에게 16채널을 보내기

OFFICIALM32의 ROUTING → p16 out에서는 16개 P16 Ultranet 채널 각각에 Main, Mix Bus, Matrix, Direct Out 등 다양한 신호를 지정하고 Tap Point를 선택할 수 있습니다.

현재 밴드 구성을 고려하면 P16에는 모든 입력을 무조건 1:1로 보내기보다 연주자가 실제로 독립 조절해야 하는 소스를 우선 배치하는 것이 좋습니다.

5부 · 예배 운용 — 5.1전원 · 준비 순서

공식 매뉴얼은 M32를 켜거나 끄기 전에 모니터 스피커의 파워 앰프를 끄거나 Mute하도록 경고합니다. 현장에서는 이 원칙을 전체 PA에 확장하여 콘솔이 먼저 켜지고 스피커가 나중에 켜지는 순서를 사용하면 안전합니다.

POWER ON
SOURCE → MIXER → SPEAKER
  1. 마이크·악기·수신기 연결
  2. M32 및 소스 장비 전원
  3. 씬/라우팅 확인
  4. 마지막에 파워드 스피커/앰프 활성
POWER OFF
SPEAKER → MIXER → SOURCE
  1. Main Mute/레벨 확인
  2. 스피커/앰프 먼저 OFF 또는 Mute
  3. M32 종료
  4. 소스 장비 정리

5부 · 예배 운용 — 5.4종료 · Scene 저장

M32는 Scene을 통해 콘솔의 설정 상태를 저장하고 다시 불러올 수 있습니다. 예배 운영에서는 “좋았던 상태를 남기는 것”만큼 무엇이 바뀌었는지 기록하는 것이 중요합니다.

  1. 예배 종료 직후 문제가 없었던 최종 상태를 Scene으로 저장합니다.
  2. Scene 이름에는 날짜와 목적을 명확히 적습니다. 예: 2026-08-09_Sunday_Service.
  3. 다음 주에 그대로 불러오기 전에 마이크·악기 패치가 동일한지 확인합니다.
  4. 48V, Routing, P16 설정처럼 실수 영향이 큰 항목은 별도의 “기준 Scene”을 유지합니다.
  5. 스피커/앰프를 먼저 Mute/OFF한 뒤 콘솔 전원을 종료합니다.

채널 Meter 자체가 움직이지 않는다

  5. Gain이 지나치게 낮지 않은지

  3. Main Stereo Bus ST 할당
  4. DCA가 내려가거나 Mute되지 않았는지
  5. Main LR Master 및 Output Routing

6부 · 빠른 해결 — 6.2피드백(하울링)이 날 때

  1. 먼저 해당 마이크 또는 그룹 레벨을 조금 내립니다. 원인을 찾기 전에 피드백을 계속 유지하지 않습니다.
  2. 어느 마이크가 원인인지 SOLO/Mute를 이용해 확인합니다.
  3. 마이크와 PA/모니터 스피커의 위치·방향을 확인합니다.
  4. 해당 채널의 불필요한 저역과 과도하게 Boost된 EQ를 확인합니다.
  5. 필요하면 RTA/GEQ를 이용하되, 무작정 깊은 노치를 여러 개 만들지 않습니다.
성가대 특히 주의멀리 있는 성가대를 크게 받기 위해 Gain과 Fader를 계속 올리는 방식은 한계가 빠르게 옵니다. 마이크 수·거리·방향·스피커 배치가 전기적 처리보다 먼저입니다.
