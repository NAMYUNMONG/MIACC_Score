# Main Portal Design

## Information Architecture
- `/MIACC_Score/`: 서비스 선택 메인
- `/MIACC_Score/score.html`: 기존 악보 콘티 작성
- `/MIACC_Score/m32/`: 기존 M32 Output Hub

## Visual Direction
- 밝고 차분한 공용 메인 배경
- Score 카드는 청록 계열, M32 카드는 기존 검정·금색 계열
- 데스크톱 2열, 모바일 1열

## Verification
- 두 HTML entry가 Vite 결과물에 존재
- 메인 카드 href의 실제 파일 존재
- Score 앱 렌더링과 M32 Hub 링크 보존
