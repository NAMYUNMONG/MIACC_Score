# Main Portal Plan

## Goal
루트 페이지에서 기존 콘티 작성 도구와 M32 운영 Hub로 명확하게 진입할 수 있는 선택 화면을 제공한다.

## Scope
- 루트 선택형 메인 페이지
- 기존 콘티를 `score.html`로 분리
- 기존 M32 Hub `/m32/` 보존
- GitHub Project Pages base path와 모바일 접근성 지원

## Success Criteria
- 두 카드가 실제 배포 경로로 연결된다.
- 기존 Score 및 M32 기능이 보존된다.
- 모바일에서 단일 열로 표시된다.
- `npm run build`와 내부 링크 검사가 성공한다.
